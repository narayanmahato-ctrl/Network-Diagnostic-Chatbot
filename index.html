Network Diagnostic Chatbot

A command-line assistant for quick network troubleshooting. Check reachability, resolve DNS records, inspect ports, test connectivity, trace routes, and review local network information from one interactive interface.

View source on GitHub Installation guide

Reachability

Run ping checks against a hostname to confirm that a remote system responds.

DNS Resolution

Resolve hostnames into IP addresses and investigate name-resolution issues.

Port Checks

Test whether a destination accepts connections on a specific TCP port.

Route Tracing

Inspect the network path toward a destination with a guided traceroute command.

$ mvn clean install
$ java -jar target/network-chatbot.jar

Chatbot> ping google.com
Chatbot> dns google.com
Chatbot> port google.com 443
Chatbot> help
